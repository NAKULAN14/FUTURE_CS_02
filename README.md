# FUTURE_CS_02 – SOC Incident Response Project

## 📌 Project Overview
This project simulates the role of a Security Operations Center (SOC) analyst. 
The objective was to monitor security logs, identify suspicious activities, 
classify alerts by severity, and document an incident response using a SIEM tool.

## 🛠 Tools Used
- Elastic Stack (ELK)
- Kibana (Discover & Lens)
- Simulated SOC logs
- GitHub for project submission

## 🔍 Key Activities
- Log ingestion and analysis using Elastic SIEM
- Identification of malware and authentication anomalies
- Alert classification (High, Medium, Low)
- Incident timeline creation
- Dashboard creation for security monitoring
- Incident response reporting

## 📁 Project Files
- **Incident_Response_Report.pdf** – Full incident response documentation
- **Screenshots/** – Evidence of log analysis and SIEM dashboard

## 🎯 Outcome
The project demonstrates foundational SOC analyst skills including alert triage,
incident analysis, reporting, and SIEM dashboard monitoring.
